## What Apex Logics Is

Apex Logics is a browser-first suite of narrow decision engines. Each tool helps you work through structured scenarios across career planning, education finance, compensation and job offers, professional licensing, immigration pathways, and workforce development outcomes.

Logic is deterministic and rule-based: identical inputs yield the same results. Everything runs in the client as standalone HTML, without outbound API calls, so you can inspect scenarios without handing over personally identifiable data.

## Usage

A practical flow looks like this:

1. Choose the engine that fits the decision you are testing.
2. Supply career, education, pay, licensing, immigration, or workforce inputs.
3. Read the deterministic outputs the engine returns.
4. Where the UI allows it, run alternate scenarios and compare them.
5. Export AP2 v2.0 JSON or Markdown when you need a portable artifact.
6. Hook automated jobs into the suite through MCP when you want machine access.

Illustrative uses:

- Weigh several job offers on pay and related terms
- Stress-test the cost side of an education plan
- Map licensing or immigration routes before you commit
- Approximate return on workforce development spend
- Hand structured JSON or Markdown to other tools downstream

## Configuration

There is no separate server config layer. Scenario knobs live in each HTML tool’s form controls; change those values to steer the engine.

External API keys are not part of the setup. Store the downloaded HTML files in one place if you want a local library, and reopen a file whenever you start a fresh run.

## FAQ

### Who should use Apex Logics?

Anyone modeling career, education finance, compensation, licensing, immigration, or workforce development decisions in a structured way.

### Is an always-on internet connection mandatory?

Engines run locally and do not call external APIs. You may still need the network to fetch a new build or open the hosted project page.

### Are results deterministic?

Yes. Calculations follow fixed rules so the same inputs should produce the same outputs.

### Can I export outcomes?

Yes. AP2 v2.0 JSON and Markdown export are supported.

### Does Apex Logics gather personally identifiable information?

Per the project profile, the tools do not collect PII.

### How do I stay on the latest version?

Grab the newest build from the [project page](https://seanparker90.github.io/apex-logics-tool-suite-2026/) and swap it in for older local HTML copies.

### A tool will not open. What next?

Check that the download finished, try an up-to-date browser, and open the HTML file directly. If it still fails, diff your copy against the current repository build.

### Where do I ask for support?

Open GitHub issues or discussions on the repository (when those channels are enabled) for reproducible bugs or project questions.
